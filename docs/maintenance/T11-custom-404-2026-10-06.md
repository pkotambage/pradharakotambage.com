# T11 — Custom 404 page

**Date:** 6 October 2026

## Implementation

- Added a branded root-level `404.html` for GitHub Pages.
- Kept the page `noindex, follow`.
- Added root-relative links to Home, Legal Guides and Search articles.
- Reused the site's shared stylesheet, navigation, footer and JavaScript.
- Added a self canonical for validator consistency.
- Added a post-deployment GitHub Actions check that requests a deliberately missing URL and verifies:
  - HTTP status remains 404;
  - the custom message is present;
  - Legal Guides and Search articles links are present.

## Completion criterion

A missing URL must continue to return HTTP 404 while providing useful navigation with working root-relative assets and links.
